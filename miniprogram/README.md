# 微信小程序

基于微信原生小程序框架（WXML / WXSS / JS）构建的 OpenWrt 路由器管理小程序。

## 目录结构

```
miniprogram/
├── app.js                       # 小程序入口，全局状态
├── app.json                     # 页面路由 + TabBar 配置
├── app.wxss                     # 全局样式
├── utils/
│   └── openwrt.js               # ubus 客户端 + 路由器管理器 + 局域网扫描 + 验证码
├── pages/
│   ├── index/                   # 路由器列表 + 局域网扫描
│   │   ├── index.js
│   │   ├── index.wxml
│   │   ├── index.wxss
│   │   └── index.json
│   ├── add/                     # 添加/编辑路由器（含图形验证码）
│   ├── dashboard/               # 控制台总览（多路由器切换）
│   ├── devices/                 # 设备管理
│   ├── traffic/                 # 流量统计（Canvas 折线图）
│   ├── firewall/                # 防火墙规则
│   └── system/                  # 系统设置（信息 / WiFi / 日志三 Tab）
└── assets/                      # 图标资源（TabBar 图标等）
```

## 开发部署

### 1. 注册小程序账号

前往 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序账号，获取 AppID。

### 2. 配置 AppID

打开 `project.config.json`（首次用微信开发者工具导入会自动生成），填入你的 AppID：

```json
{
  "appid": "你的AppID",
  "projectname": "OpenWrtManager"
}
```

### 3. 配置合法域名（request 白名单）

小程序要访问路由器，需要在微信公众平台配置服务器域名：

**开发阶段**：微信开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名」即可，局域网地址可直接访问。

**正式发布**：进入 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 开发 → 开发管理 → 开发设置 → 服务器域名，添加 request 合法域名。

> ⚠️ **注意**：微信小程序正式版只允许 HTTPS 域名。如果用户路由器只有 HTTP，需要在「开发者工具-不校验域名」下体验，或引导用户为路由器配置 HTTPS 证书。

### 4. 用微信开发者工具导入

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 点击「导入项目」→ 选择 `miniprogram/` 目录
3. 填入 AppID → 导入
4. 点击「编译」预览效果

### 5. 发布

1. 点击「上传」→ 填写版本号和描述
2. 登录微信公众平台 → 版本管理 → 提交审核
3. 审核通过后发布

## 功能说明

| 页面 | 功能 |
|------|------|
| 路由器列表 | 局域网扫描发现路由器、已保存路由器列表、长按删除 |
| 添加路由器 | 手动填写 IP/端口/账密、图形验证码、测试连接、记住密码/自动登录 |
| 控制台 | 系统信息、内存进度条、网络接口状态、多路由器下拉切换 |
| 设备管理 | DHCP 租约列表、搜索过滤、一键踢出设备 |
| 流量统计 | 按接口选择、Canvas 实时折线图、3 秒轮询 |
| 防火墙 | 读取 UCI 规则、添加/删除规则、立即生效 |
| 系统设置 | 系统信息、WiFi 密码修改、系统日志（三 Tab） |

## 与手机 APP 的区别

| 特性 | 微信小程序 | 手机 APP |
|------|-----------|----------|
| 安装方式 | 扫码即用，无需安装 | 需下载 APK 安装 |
| 局域网扫描 | 支持（受微信限制，候选 IP 较少）| 完整支持 |
| 图形验证码 | Canvas 2D 实现 | 文字验证码（简化）|
| 网络限制 | 正式版需 HTTPS 域名 | 无限制，支持 HTTP |
| 流量图表 | Canvas 2D 绘制 | RN 原生柱状图 |
| 离线使用 | 需微信在线 | 完全本地运行 |
